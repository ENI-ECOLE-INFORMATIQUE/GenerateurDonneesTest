🔍 Le code expliqué — notions JS utilisées

Math.random() + Math.floor()

Math.random() renvoie un nombre entre 0 et 1 ; multiplié puis arrondi avec Math.floor(), on obtient un entier aléatoire : la base du hasard.

tableau[index]

Les tableaux sont numérotés à partir de 0. PRENOMS[0] vaut "Marie". Piège classique : le dernier élément est à length - 1.

objets { clé: valeur }

Une "personne" est un objet : { prenom: "Marie", age: 28 }. On lit une valeur avec personne.age.

querySelector et addEventListener

document.querySelector() retrouve un élément HTML, et addEventListener("click", ...) exécute une fonction quand on clique. C'est la base de toute page interactive, sans framework.

map() et join()

map() transforme chaque élément d'un tableau en autre chose (une ligne de tableau ou de CSV) ; join() colle les éléments en une seule chaîne.

template literals : `texte ${variable}`

Les backticks permettent d'insérer des variables dans une chaîne — plus lisible que la concaténation avec +. Utilisés partout dans ce générateur.

JSON.stringify()

Convertit des objets JS en texte JSON — utile pour préparer des fichiers de données exploitables par d'autres outils.

Blob et URL.createObjectURL

Pour le CSV : on fabrique un "fichier" en mémoire (Blob), on lui donne une adresse temporaire (createObjectURL), et on déclenche le téléchargement via un lien cliqué par programmation.

Démo pédagogique — chaque bouton illustre une notion JS réutilisable dans vos activités de test.
