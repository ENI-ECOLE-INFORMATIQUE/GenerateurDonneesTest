# GenerateurDonneesTest

Démo JavaScript pour testeurs logiciels : générez des jeux de données, explorez les cas limites et découvrez le code qui les produit. Le projet utilise du HTML, du CSS et du JavaScript natifs, sans framework ni dépendance à installer.

## Structure du projet

```text
GenerateurDonneesTest/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── generateur-donnees-test.html
├── LICENSE
└── README.md
```

- `generateur-donnees-test.html` contient la structure de la page.
- `css/style.css` contient les styles.
- `js/script.js` contient la génération des données, le tri, la copie JSON et l’export CSV.

## Lancer la démo

Ouvrez `generateur-donnees-test.html` dans un navigateur. Aucun serveur ni installation n’est nécessaire.
